# Notebooks – Model Development

This directory contains Jupyter notebooks used for data exploration, preprocessing, feature extraction, model training, and evaluation for Amazon Product Review Sentiment Analysis.

## Purpose

- Explore and understand review datasets.
- Clean and preprocess customer reviews.
- Perform text feature extraction using TF-IDF.
- Train and evaluate machine learning classification models.
- Compare model performance and select the best-performing model.

These notebooks document the experimentation and model development process behind the sentiment analysis application.
