# Schema – API and Review Service

This directory contains the schema definitions and service logics used by the backend of the Amazon Product Review Sentiment Analysis application.

## Files

- `api.py` – Contains API-related schema definitions and supporting logic.
- `review_service.py` – Handles review-related service functionality used by the application.

## Purpose

The schema directory helps organize the backend's API and review service components, keeping them separate from the main application entry point.

These modules support the integration between the FastAPI backend and the review analysis workflow.
